# PlayStation 5 & Accessories Storefront 🎮

A modern, client-side e-commerce web application built with **React**, showcasing PlayStation 5 consoles and official gaming accessories. 

## ✨ Features

* **Product Catalog:** Browse a curated collection of PS5 consoles, controllers, headsets, and accessories.
* **Product Detail Pages:** Dedicated views for each item featuring specifications, pricing, and product imagery.
* **Shopping Cart:** Interactive cart functionality allowing users to add items, update quantities, remove products, and view real-time subtotal calculations.
* **Responsive Design:** Fully optimized for seamless browsing across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **Frontend:** React (Hooks, State Management, React Router)
* **Styling:** CSS3
* **Architecture:** Client-side only (SPA)
